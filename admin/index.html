Connect Supabase

The admin isn't connected to a database yet.

  1. Create a free project at supabase.com.
  2. Open SQL Editor, paste everything from supabase/schema.sql, and click Run.
  3. In Project Settings → API, copy the Project URL and anon public key into supabase-config.js.
  4. In Authentication → Users, add your admin user, then run the "make yourself an admin" snippet at the bottom of schema.sql.
  5. Reload this page and sign in.
